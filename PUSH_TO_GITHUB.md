# 🚀 Quick Start - Push to GitHub

## ⚡ Fastest Way (Copy & Paste)

```bash
# 1. Initialize git (skip if already done)
git init

# 2. Add all files
git add .

# 3. Commit
git commit -m "Initial commit: BrewCall SaaS platform"

# 4. Create repo on GitHub first, then:
git remote add origin https://github.com/YOUR_USERNAME/brewcall.git

# 5. Push
git branch -M main
git push -u origin main
```

**Replace `YOUR_USERNAME` with your actual GitHub username!**

---

## 📝 What You Need to Do

1. **Go to GitHub**: https://github.com/new
2. **Create repository** named `brewcall`
3. **Copy the commands above** (replace YOUR_USERNAME)
4. **Run in terminal** in your project folder
5. **Done!** ✅

---

## 🔄 Daily Workflow

```bash
# After making changes:
git add .
git commit -m "Your message here"
git push
```

That's it! Your changes are now on GitHub.
